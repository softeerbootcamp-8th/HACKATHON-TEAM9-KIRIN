## 1. 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | 오다가다 |
| 도메인 | 커뮤니티(단지) 내 공용 진열함을 통한 비대면 중고거래 — 판매자가 진열함에 물품을 보관하면 구매자가 QR 스캔 → 결제 → 진열함 개방으로 수령한다 |
| 플랫폼 | **모바일 웹 전용** (Figma 프레임 기준 375~393px 뷰포트). 데스크톱 반응형 레이아웃은 정의되어 있지 않다 |
| 앱 구성 | 판매자앱(진열함 등록·예약·판매 관리) / 구매자앱(QR 스캔·상품 상세·결제) — 동일 코드베이스 내 역할별 화면 플로우로 구현 |
| 테마 | 라이트 전용 (다크 모드 미정의) |

> 사용자에게 노출되는 서비스명은 "오다가다"(로고 워드마크·브라우저 탭 타이틀 등)이다.
> `KIRIN` 은 리포지토리·패키지명 등 내부 프로젝트 코드네임으로만 남아 있다
> ([§8](#8-도메인-용어) 참고).

## 2. 디자인 원칙

1. **상태는 색 + 텍스트로 이중 표시한다.** 진열함의 비어있음/예약중/판매중 같은 상태는
   배경색만으로 구분하지 않고 라벨 텍스트를 항상 함께 노출한다([§6](#6-상태--인터랙션-규칙)).
2. **거래 핵심 정보를 최상단에 배치한다.** 상품명·가격·진열함 위치·판매자 신뢰 정보(등록일,
   거래 횟수)를 스크롤 없이 먼저 보여준다.
3. **되돌리기 어려운 액션은 한 번 더 확인한다.** 취소, 삭제, 진열함 잠금 해제처럼 되돌릴 수
   없는 동작은 모달/바텀시트로 재확인 단계를 거친다.
4. **모바일 단일 컬럼 + 하단 고정 CTA.** 화면은 한 컬럼으로 구성하고, 다음 행동(확정하기·예약하기
   등)은 화면 하단 고정 버튼으로 명확히 드러낸다.

## 3. 디자인 토큰

`src/styles/globals.css` 가 단일 출처(SSOT)여야 한다. 아래는 Figma 기준 목표 값이며,
**아직 코드에 반영되지 않았다** — 구현 시 이 표를 그대로 옮긴다.

### 3.1 색상

```css
:root {
  /* 배경 · 표면 */
  --color-bg: #ffffff;
  --color-surface: #ffffff;
  --color-surface-2: #fafafa;     /* 칩 · pill 배경 (예: "내 리스트" 버튼) */
  --color-border: #d9d9d9;

  /* 텍스트 */
  --color-text: #1f1f1f;          /* 제목 · 강조 (로고, 헤딩) */
  --color-text-sub: #333333;      /* 본문 */
  --color-text-muted: #8c8c8c;    /* 보조 · 캡션 · placeholder · disabled */

  /* 액센트 */
  --color-primary: #4d25c5;       /* 버튼 primary, 바텀시트 CTA */
  --color-primary-hover: #3c1c9c; /* Figma에 hover 스펙 없음 — 10% 다크닝 추정치, 확정 시 갱신 */

  /* 상태(진열함 · 배지) */
  --color-success: #1cb80e;       /* 수락(Accept) 상태 아이콘 */
  --color-danger: #d64545;        /* 판매중 배지 · 진열함, 삭제/실패 계열 */
  --color-danger-bg: #fcebeb;
  --color-info: #3b6fd4;          /* 예약중 진열함 */
  --color-info-bg: #eaf0fb;

  /* 비활성 */
  --color-disabled-bg: #e5e5e5;
  --color-disabled-text: #8c8c8c;
}
```

> `--color-warning` 은 Figma 컴포넌트에서 발견되지 않았다. 화면 명세가 추가되며 필요해지면
> 그때 정의한다(임의로 값을 만들어 넣지 않는다).

### 3.2 타이포그래피

```css
--font-sans:
  "Pretendard", -apple-system, "Apple SD Gothic Neo", system-ui,
  "Noto Sans KR", "Segoe UI", sans-serif;
--font-num: ui-monospace, var(--font-sans);
```

- 모든 커스텀 컴포넌트(Button/Header/ItemList/Logo 등)는 **Pretendard**
  (Regular/Medium/SemiBold/Bold)를 사용한다. 저장소에 아직 폰트 자산이 없으므로
  구현 시 `pretendard` npm 패키지 또는 자체 호스팅 `@font-face` 추가가 필요하다.
- 일부 와이어프레임 텍스트(레전드 라벨, 그리드 제목 등)는 Figma 기본 폰트인 Inter로
  남아 있다 — 이는 와이어프레임 제작 중 미정리된 부분으로 보이며, 실제 구현은
  Pretendard로 통일한다.
- 본문 16px / 제목 20~24px(Bold) / 보조·캡션 12~14px 스케일을 사용한다.
- 금액·시간 등 숫자를 나열할 때는 `.tabular`(tabular-nums)를 적용한다.

### 3.3 간격 · 반경 · 뷰포트

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px;

--radius-sm: 8px;    /* 버튼 · 입력 필드 · 리스트 아이템 · 진열함 셀 · 카드 */
--radius-lg: 16px;   /* 바텀시트 · 모달 상단 모서리 */
--radius-pill: 999px; /* 배지 · 칩 */

--header-height: 56px;   /* 하위 화면 Header 컴포넌트 높이 */
--viewport-max: 430px;   /* 모바일 전용 뷰포트 상한 — 넓은 화면에서는 중앙 정렬 + 레터박스 */
```

> 기존 `--radius-md: 12px` · `--container-max: 1200px` · `--gnb-height: 64px` 는
> Figma 컴포넌트 어디에서도 쓰이지 않는 값이다. 데스크톱 GNB 레이아웃 전제가
> 이번 와이어프레임과 맞지 않으므로 [§4](#4-레이아웃--내비게이션)에서 대체한다.

## 4. 레이아웃 · 내비게이션

와이어프레임은 데스크톱 GNB가 아니라 **모바일 앱 셸** 구조다. 기존 `Gnb`/`PageContainer`
(데스크톱 상단 내비 + 1200px 컨테이너) 전제는 이 구조와 맞지 않으므로, 화면 구현 시
아래 구조로 교체를 검토한다.

### 4.1 앱 셸

- 뷰포트는 `--viewport-max`(430px) 로 제한하고 중앙 정렬한다. 더 넓은 화면(태블릿/데스크톱
  브라우저)에서는 좌우를 레터박스 처리한다.
- Figma의 `Status-bar`/`HomeIndicator` 심볼은 **네이티브 기기 프레임을 흉내 낸 프로토타입
  목업**이다. 실제 모바일 브라우저가 자체 상태 표시줄을 가지므로 웹 구현에는 그대로
  옮기지 않는다.

### 4.2 헤더

- **홈 화면**: 좌측 정렬 워드마크만 노출하는 `Logo` 컴포넌트(24px Bold) — 별도 뒤로가기 없음.
- **하위 화면**: `Header` 컴포넌트, 높이 56px.
  - 좌측: 뒤로가기 아이콘(옵션) + 중앙 타이틀(20px SemiBold) + 우측: 텍스트 액션(예: "수정하기",
    옵션). 세 슬롯 모두 비어 있을 수 있다.

### 4.3 바텀시트

- 진열함 예약처럼 화면 전체 전환 없이 처리할 보조 액션은 `BottomSheet` 로 띄운다.
- 상단 모서리 반경 16px, 상단 핸들바(36×4px, `--color-border`) 포함, 내부 CTA는 `Button`
  primary 스타일을 그대로 사용한다.
- shadcn/ui 기준으로는 `Dialog` 보다 `Drawer`/커스텀 바텀시트 프리미티브 도입을 검토한다
  (현재 `src/components/ui` 에 없음).

### 4.4 하단 탭바

- 와이어프레임에는 전역 하단 탭바가 없다. 판매자앱/구매자앱 전환 및 화면 간 이동은 모두
  각 화면의 `Header` 뒤로가기 또는 명시적 CTA로 이루어진다. 탭바가 필요해지면 이 섹션에
  추가한다.

## 5. 컴포넌트

`src/components/ui`(shadcn/ui 프리미티브)로 시작한다. 새 화면에 필요한 프리미티브는
CLI로 추가한다: `pnpm dlx shadcn@latest add <name>`.

### 5.1 실제 UI 컴포넌트 (Figma `Components` 섹션 기준)

| 컴포넌트 | Variant | 용도 | 비고 |
|------|--------|------|------|
| `Logo` | – | 홈 화면 워드마크 | 24px Bold, `--color-text` |
| `Status-bar` / `HomeIndicator` | – | 기기 프레임 목업 | 웹 구현 대상 아님 ([§4.1](#41-앱-셸)) |
| `Button` | `primary` / `secondary` / `disabled` | 화면 하단 고정 CTA(확정하기 등) | shadcn `Button` 의 `variant` 로 매핑(`primary`→`default`, `secondary`→`outline`) |
| `Header` | `Default` / `뒤로텍스트` / `뒤로텍스트수정` | 하위 화면 상단 내비게이션 | 좌: 뒤로가기, 중: 타이틀, 우: 텍스트 액션 슬롯 |
| `ItemList` | `Default` / `Checkbox` / `CheckboxCheck` / `Accept` / `Cancel` / `Delete` | 내 리스트 · 거래 요청 목록의 행 아이템 | 위치 2줄 보조 텍스트 + 우측 상태 아이콘/체크박스 |
| `BottomSheet` | – | 진열함 예약 등 보조 액션 패널 | [§4.3](#43-바텀시트) |
| 진열함 셀(신규 domain) | `empty` / `reserved` / `selling` | 진열함 현황 그리드(4열) | Figma엔 별도 컴포넌트로 분리돼 있지 않음 — 구현 시 `components/domain/locker-cell.tsx` 로 승격 권장 |
| 상태 배지(신규 domain) | 예: `판매중` | 상품 상세 등에서 상태 pill 표시 | `bg-[--color-danger-bg] text-[--color-danger]`, `radius-pill` |

### 5.2 Figma 전용 "디자인 명세 주석" 컴포넌트 — 구현 대상 아님

`Components` 섹션에는 실제 앱 UI가 아니라 **디자이너가 개발자에게 화면을 설명하기 위한
주석용 컴포넌트**가 함께 있다. 코드로 옮기지 않는다.

| 컴포넌트 | 용도 |
|------|------|
| `Description Badge` (A~J) | 스크린샷 위에 붙는 번호 배지 |
| `Description Card` / `Description Note` / `Description Line` | 화면별 `*_Note` 프레임에서 사용하는 설명 카드/말줄임/연결선 |
| `Policy Card` | "관련 정책" 설명 블록 |
| `Usecase Card` | "Usecase" 시나리오 설명 블록 |

도메인 컴포넌트(카드, 리스트, 배지 등)는 화면 구현이 진행되는 대로
`src/components/domain` 에 추가하고 위 5.1 표를 갱신한다.

## 6. 상태 · 인터랙션 규칙

- **진열함 상태 3종은 색+텍스트로 함께 표시한다.**
  - 비어있음: `--color-border` 테두리, 흰 배경, `--color-text-muted` 텍스트
  - 예약중: `--color-info-bg` 배경, `--color-info` 테두리/텍스트
  - 판매중: `--color-danger-bg` 배경, `--color-danger` 테두리/텍스트
- **Button `disabled`**: 필수 입력/선택이 완료되지 않으면 `--color-disabled-bg` 배경 +
  `--color-disabled-text` 텍스트로 비활성 표시하고 클릭을 막는다.
- **되돌리기 어려운 액션 확인**: 예약 취소, 리스트 삭제, 진열함 잠금 해제는 모달/바텀시트로
  한 번 더 확인받는다(`08 모달 · 사물함 잠금 해제`, `08-1 모달 · 예약중입니다` 참고).
- **거래 항목(`ItemList`) 좌측 스와이프**: `Delete` variant는 삭제 액션이 항목 위에 오버레이되는
  형태로 표현되어 있다 — 스와이프 삭제 패턴으로 구현한다.
- 금액·시간 등 숫자는 `.tabular`(tabular-nums)를 적용한다.
