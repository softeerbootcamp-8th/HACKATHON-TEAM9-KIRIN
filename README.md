## 프로젝트 구조

```
.
├── backend/    # Spring Boot 애플리케이션 (Java 21, Gradle)
└── frontend/   # 프론트엔드 애플리케이션
```

## Backend

- Java 21 / Spring Boot 4.1.1 / Gradle 9.5.1
- Spring Web MVC, Spring Data JPA, Lombok

### 실행

```bash
cd backend
./gradlew bootRun
```

### 테스트

```bash
cd backend
./gradlew test
```
